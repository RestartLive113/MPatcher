MPatcher 0.3.9.2 Alpha for MachineCraft 0.248c

Русский
Это экспериментальная сборка Magnification R68c на основе R66. Исправлен учёт масштаба в защитах движения и соединителей.
Запустите MPatcherInstaller.exe, выберите папку MachineCraft и установите пакет.
Установщик скачивает именно канал Alpha и проверяет размер и SHA-256 пакета.
После установки игра запускается обычным способом; специальный ярлык не нужен.
Для следующих Alpha-обновлений выберите Settings -> MPatcher -> Update Channel -> Alpha.
Для возврата выберите Stable и нажмите кнопку обновления либо установите Stable 0.3.8.
UserData установщиком не изменяется. Перед тестированием сохраните копию важных машин.
Физика ещё дорабатывается: тряска/просадка подвески возможны. При столкновении машин
разного масштаба отношения масс пока некорректны. Скрипты, AGD, вода и сетевая игра
требуют дальнейших проверок. Это не подтверждение полного совпадения с физикой 100%.
Если отображается wrong DLL, проверьте logs/MPatcher_*.log на SCRIPT-DLL-COMPAT
MPATCHER_REJECT: старые ручные DLL-копии в McnCraft_Data могут блокировать скрипты.

English
Experimental Magnification R68c build based on R66. Motion and joint safety checks now account for scale. Run MPatcherInstaller.exe,
select your MachineCraft folder and install. This installer downloads Alpha and
checks the package size and SHA-256. Launch the game normally; no special flags
or shortcut are needed. Select Alpha in Settings -> MPatcher -> Update Channel
for later Alpha updates. Select Stable and update to return to Stable 0.3.8.
The installer preserves UserData. Back up important machines before testing.
Suspension stability is still being developed. Relative masses in collisions
between different craft scales are not yet correct. Scripts, AGD, water and
multiplayer require further testing. Full physics equivalence is not claimed.
